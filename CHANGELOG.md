# Changelog

## 1.1.0

### Minor Changes

- Walkthroughs: press ⌥⇧S (configurable in Settings → Hotkey) to record your screen while you talk, click and draw (⇧-drag ink, ⇧-click pins); Tick transcribes on device and pastes a numbered contact sheet plus a timestamped transcript into the front app, ready for an AI agent.

## 1.0.0

- First release of Tick: on-device voice-to-text for macOS, rewritten as a native Rust/GPUI app.
- Download from GitHub Releases or install with `brew install --cask deepanshumishraa/tap/tick`.
